# Gloss 项目总览（DESIGN）

> 版本：V1.0（2026-09-26）。本文是项目唯一决策记录与文档索引；详细设计见下方文档索引，各主题以对应文档为权威，本文不重复细节（防多源漂移）。
> 仓库：`~/Git/gloss`。

## 1. 产品一句话

**Gloss（划词即释）**：Mac 系统级英文阅读助手——选中文本/截图/打开 PDF，一个动作即得带读音的词典级解释与语境翻译、生词提取和专业文章逻辑解读，由用户自配的大模型（默认 MiniMax M3 多模态）驱动。

## 4. 里程碑总览（细目见两份详设的里程碑章节）

- **M1 划词 + 截图 + 文本精读**：Services 右键 / ⌥D 划词 / ⌥S 截图三条触发通道；单词/句子/段落/截图四类卡片；文本精读窗（全文翻译/生词表/术语表/逻辑解读）；设置 + 首启引导 + 历史 + 缓存 + 离线 TTS。
- **M2 PDF 精读**：打开/拖拽 PDF → PDFKit 视图 + 按页渲染图多模态解析（当前页/选区/全文），页粒度缓存。
- **M3 增强**：生词本与导出（CSV/Anki）、MiniMax 在线 TTS、选区跟随小图标、多 Provider 并行对照、第三方词典极速首屏（默认关）、中→英反向查询评估。
