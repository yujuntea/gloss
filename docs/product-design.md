# Gloss 产品设计文档

> 版本：V1.1（2026-09-27）。权威范围见 [DESIGN.md](DESIGN.md) 文档索引；决策以 DESIGN.md §2 为准，本文不重复决策理由。
> 里程碑标记：〔M1〕〔M2〕〔M3〕标注每个功能的落地里程碑；未标注的为基础能力默认 M1。

## 1. 产品定位与设计原则

**定位**：不是翻译工具，而是"LLM 阅读理解助手"——补齐传统划词词典（无语境/无深度解释）与网页 ChatBot（交互成本高/无读音/结果不沉淀）之间的空白。

**三条设计原则**（所有交互争议以此裁决）：

- **P1 零打断**：任何查询不离开当前阅读上下文——不切窗口、浮窗不抢键盘焦点、浮窗弹出位置避让被选中的文本。两个例外：**例外 1** ≥400 词长选段直接开精读窗，属预期的显式深读动作；**例外 2** 点击截图卡缩略图打开图片放大窗（密集截图在 160pt 缩略图里正文不可读，大图上点词的前置动作），属预期的显式细看动作。两者都是用户显式触发的一次性深看，与"浮窗不抢焦点"的默认行为同级，不引入第二种窗口行为范式；图片窗内点词的结果仍由浮窗承载，浮窗不抢图片窗焦点。
- **P2 一秒钟**：唤起后无需二次选择即开始出结果——类型自动路由、流式渲染、缓存命中即回显；用户的下一个动作只在"想朗读/想复制/想深读"时发生。
- **P3 所见即可问**：屏幕上看得见的（划选文本、框选区域、PDF 页面）都能查询；图像理解统一交给多模态模型（D5），不做本地识别，减少一层"识别错→解释错"的间接链路。

**目标用户**：中文母语、在 Mac 上高频阅读英文技术/专业内容、持有大模型 API Key 的进阶用户（首个用户即我们自己）。

## 2. 核心使用场景走查

每个场景给出：触发链 → 界面序列 → 时长预期 → 异常分支。这是第 4–5 章界面与交互规格的需求来源。

### S1 生词即查〔M1〕

在读英文技术文档（浏览器）时遇到 "idempotent"。

1. 用户划选该词 → 按 **⌥D**（或右键 → 服务 →「Gloss 查词」）。
2. 浮窗在选区下方弹出（无选区信息时在鼠标右下方），宽 400pt，不抢焦点；卡片先出骨架（单词名 + 音标占位 + 加载指示）。
3. 流式渲染：标题行（词 + 🔊 + 美/英音标）→ **语境义**（置顶，结合上下文的准确含义）→ 词性与常用义 → 搭配 → 例句 → 辨析。
4. 用户点 🔊 听美音；再点 US/UK 切换段听英音。
5. 阅读继续：按 ESC 或点击浮窗外任意处关闭。

时长预期：按键→浮窗出现 <0.2s；→首字内容 <1.5s（缓存命中 <0.1s）。
异常分支：取词失败（目标 App 拒绝 AX 且 ⌘C 兜底也失败）→ 浮窗显示"未能获取选中文本"+「改用截图查询」按钮（引导 ⌥S）；未配置 API Key → 顶部提示条「未配置 API Key · 去设置」。

### S2 长难句拆解〔M1〕

"意思拿不准的句子"，如带从句嵌套/倒装的长句。

1. 划选整句 → ⌥D。路由判定为句子（<60 词且以句末标点收尾）。
2. 句子卡：先出**翻译**（最急需），再流式补**结构拆解**（主干/修饰/从句缩进列表）与**难点说明**（歧义/习语/倒装，解释"为什么这么理解"）。
3. 句中难词/习语以 2–3 个小词条附在卡底，点击任一词条切换为该词的单词卡，卡顶出现「← 返回句子」。

异常分支：句子达 60 词及以上 → 按段落路由（对照翻译更适合），用户可手动切到「句子」。

### S3 段落翻译 + 难词〔M1〕

1. 划选一段（<400 词）→ ⌥D → 段落卡：译文流式输出；随后出**难词表**（3–6 个，按"对理解的重要性"排序，含音标与文中义）。
2. 难词条点击切换单词卡（词条尾随 🔊 小图标可单独朗读），可返回。
3. 超过 400 词 → 自动进入**精读窗**（文本模式，见 S4）。

### S4 长文精读〔M1〕

整篇文章/长选段的理解。

1. 划选长文（≥400 词）或点击卡片底部的「展开精读」→ 打开**精读窗**（标准窗口，可长驻）。
2. 左栏原文（Markdown 纯文本呈现，等宽可换行），右栏四个 Tab（界面标签用短名「翻译/生词/术语/解读」，下文以全名描述）：
   - **全文翻译**：分段左右对照，专业术语首次出现处保留英文括注；
   - **生词表**：top 10–20，按重要性排序，逐项音标/文中义/原文例句/🔊，〔M3〕一键入生词本；
   - **术语表**：仅专业文章出现——术语/领域/通俗解释；
   - **逻辑解读**：主线、论证结构（观点→证据→结论）、关键转折、结论、背景补充。
3. 长文自动分批请求（防输出截断），分批进度显示在 Tab 角标；已完成分批先行可读。
4. 精读结果按（文本哈希+模型+prompt 版本）缓存，重开秒显。

### S5 屏幕内容截图即查〔M1〕（替代"拍照发 MiniMax"）

图表、视频画面、图片、不可选中的网页元素里的英文。

1. 按 **⌥S** → 系统截图取景（框选区域）→ 松手。
2. 浮窗弹出**截图卡**：顶部缩略图 + 默认动作直接执行——**读图解释**：整图发 M3，返回「识别内容（忠实转写）→ 翻译与解释（图表/界面先说明它展示什么，再解释关键信息）→ 要点」。
3. **图上点词**：在缩略图（原始截图，**不预抽词、不做本地 OCR**）上点击**任意位置** → 把原图 + 点击坐标（归一化百分比，量化到 1% 网格）发给 M3 → 由模型判断该处是什么词并输出单词卡（语境义取该词在本图语境中的含义）；卡顶「← 返回整图解释」。正文不可选中，这是截图场景下对单个词深挖的唯一路径。实测 4–14s，明显慢于纯文本查词；超时按 §9 走错误态 +「重试」。
4. 底部操作：重新截图 / 复制识别文本 / 朗读识别文本（TTS 读的是模型转写的文本）。

时长预期：松手→浮窗 <0.3s；读图结果首字 <3s（多模态略慢于纯文本）。
异常分支：框选时按 ESC 取消（截图子进程退出码识别）→ 静默返回不弹窗；点击处无可识别英文词 → 模型回"未找到可查询的英文单词"并列出图中主要词，正常展示。

### S6 PDF 论文/报告精读〔M2〕

1. 菜单栏图标 →「打开 PDF 精读」选文件，或直接把 PDF 拖到菜单栏图标。
2. 精读窗（PDF 模式）：左栏 PDFKit 原文（翻页/缩放/页内选中），右栏四 Tab（同 S4）+ 粒度切换（当前页/全文；页内划词走浮窗卡片管线，不占右栏档位）。
3. 「解析当前页」：该页渲染成图（有文本层则附带文本层参考）→ 多模态解析 → Tab 结果；翻页不丢（页粒度缓存）。
4. 「解析全文」：执行前确认页数与预估 token（多页文档=可观的 API 费用）；逐页后台执行 + 进度条 + 可随时取消（已完成页保留缓存）；先完成的页可先读；全部完成后逻辑解读 Tab 汇总全篇。
5. PDF 页内选中文本 → 复用划词管线（取的是文本层，无 OCR），浮窗出单词/句子卡。

### S7 首次配置与权限引导〔M1〕

1. 首启向导 4 步：欢迎（定位一句话）→ 配置模型（默认 MiniMax，选国内/国际 + 贴 API Key + 「测试连接」；可跳过）→ 触发方式（默认三条通道全开；按需授权：⌥D 需辅助功能、⌥S 需屏幕录制，各带「打开系统设置」+「我已授权，重新检测」）→ 完成（内置示例句，点击「立即试查」直接演示单词卡；跳过了 Key 配置则该按钮禁用并提示先完成配置）。
2. 权限引导为**检测式**：不用权限的通道（Services 右键）永远可用；用到未授权的通道时才弹引导，不预索取。

## 4. 查询浮窗详设

### 4.1 窗口行为

| 属性 | 规格 |
|---|---|
| 类型 | `NSPanel`：nonactivating（不抢键盘焦点）+ floating 层级；`canJoinAllSpaces` + `fullScreenAuxiliary`（全屏视频画面也能弹出，支撑 S5） |
| 定位 | 优先**选区矩形**下方偏右 12pt（取词时若能从 AX 拿到选区 bounds）；否则鼠标位置右下 12pt。下方空间不足翻转到上方；对目标屏幕 `visibleFrame` 钳制（含 Dock/刘海口径）；与选区矩形重叠时按"下方→上方→左侧"顺序避让 |
| 尺寸 | 宽固定 400pt；高自适应，上限 = 鼠标所在屏高的 65%，超出内部滚动 |
| 关闭 | ESC / 点击浮窗外任意位置 / 新查询触发时原地刷新（不叠新窗）；📌固定后不自动关闭。ESC 实现为面板可见期间注册的全局热键（消费式、随显隐装拆、无需辅助功能权限）——面板可见期间按 ESC 只关面板，与目标 App 的 ESC 行为互斥，属有意取舍 |
| 多屏 | 跟随鼠标所在屏幕，不跨屏 |
| 焦点 | 永不成为 key window；浮窗内按钮用鼠标点击即可交互（接受鼠标事件） |

### 4.2 结构分区（自上而下）

1. **顶栏**（32pt）：查询类型 Segmented（词｜句｜段｜读图〔仅截图卡〕；自动路由置灰高亮默认项，可点改）；右侧：📌固定、⚙️设置快捷、✕关闭。
2. **内容区**：当前卡片（见 4.3），流式增量渲染。
3. **底部操作条**（36pt）：左侧来源标识（通道图标 + 「缓存」徽标）；右侧动作按卡片类型变化（朗读 / 复制 / 展开精读〔仅段落卡与截图卡〕 / 重新截图〔仅截图卡〕）。

### 4.3 卡片规格

**① 单词卡**

```
┌──────────────────────────────────────┐
│ idempotent                    🔊 US│UK│  ← 词（大字号）+ 朗读按钮 + 音色切换
│ /ˌaɪdemˈpɪtənt/ /ˌaɪdəmˈpɪtənt/        │  ← 美音 / 英音 IPA
│ ● 语境义  指同一请求重复执行，结果不变     │  ← 置顶突出（青底块）
│ 词性与释义                              │
│  1. adj. 幂等的（数学/计算）…             │
│ 高频搭配                                │
│  idempotent operation — 幂等操作         │
│ 例句                                    │
│  1. POST is not idempotent.（…）        │  ← 点击例句整句朗读
│ 辨析 ▸                                  │  ← 默认折叠，点开
├──────────────────────────────────────┤
│ [选区] 词查询 · 缓存 │ 🔊 📋              │
└──────────────────────────────────────┘
```

字段顺序即模型输出顺序（见 tech-design Prompt 章节）；「语境义」在无上下文时显示"（通用）"+最常用义。折叠区：辨析。

**② 句子卡**：顶部灰色小字原文（两行截断，点开全文）→ **翻译**（重点字号）→ 结构拆解（缩进列表：主干加粗、修饰/从句逐层缩进，每项一句"为什么这么理解"）→ 难点（习语/倒装/指代/省略 1–3 条）→ 卡底**句中难词** 2–3 词条（词/音标/文中义；点击词条切单词卡，卡顶出现「← 返回句子」；词条尾随 🔊 图标点击朗读——词条交互全文统一为"点击主体=切卡、🔊=朗读"，见 §4.3③；与截图卡「← 返回整图」共用面板内导航栈，tech-design §7）。底部：🔊 朗读原句。

**③ 段落卡**：译文（流式）→ 难词表（横排 chips：词 + 音标 + 文中义；点击 chip 主体切单词卡，chip 尾随 🔊 图标点击朗读——**词条交互统一规则**：全文所有词条/难词组件均为"点击主体=切单词卡、尾随 🔊=朗读"，不使用长按/右键手势）。

**④ 截图卡**

```
┌──────────────────────────────────────┐
│ [缩略图 · 宽度铺满 · 原始截图可点]       │  ← 高度 ≤160pt 等比；点任意位置查词
│ ● 识别内容  “…”                            │  ← 正文不可选中（MarkdownView 未开 textSelection）
│ 翻译与解释  …                           │
│ 要点  …                                 │
├──────────────────────────────────────┤
│ [⌥S] 读图查询 │ 🔊 📋 ⟲重截 ←返回整图     │
└──────────────────────────────────────┘
```

缩略图上点击 = 图上点词（光标十字提示）；返回整图解释按钮仅点词后出现。

**加载态**：骨架（标题条 + 3 行占位）+ 流式光标；若收到模型思考流（M3 混合推理）显示「思考中…」细字指示，不展示思考内容。
**错误态**：错误图标 + 人话文案 + 「重试」；429/服务端错误已自动重试 2 次（文案注明"已自动重试 2 次仍失败"）；超时不自动重试（超时≠限流），直接出错误态。
**缓存态**：即时渲染完整结果 + 「缓存」徽标 + 「重新查询」链接（跳过缓存）。

### 4.4 交互规则矩阵（通道 × 行为）

| 动作 | 行为 |
|---|---|
| 选中文本 + ⌥D | AX 取词（150ms 预算）→ 失败自动 ⌘C 兜底（300ms）→ 再失败出降级提示卡 |
| 选中文本 + 右键→服务→Gloss 查词 | 直接以服务传入文本查询（免权限路径） |
| ⌥S | 唤起系统框选 → 成功则查询，取消则静默返回 |
| 查询进行中再次触发 | 取消旧流式请求，浮窗原地切新内容 |
| ESC / 外部点击 | 关浮窗并停止未完成的 TTS |
| 浮窗内点按钮 | 不改变当前 App 焦点 |
| 划选超长（≥400 词） | 直接开精读窗（文本模式），浮窗不弹 |
| 中文为主选中文本 | 路由到「中→英表达查询」〔M3 评估，M1 显示"即将支持"〕 |

路由阈值（与 tech-design §4.1 同源，此处为产品侧规格）：≤3 词且无句中标点/句末标点→词卡；带句末标点且 <60 词→句卡；其余 <400 词→段落卡；≥400 词→精读窗。

## 5. 触发通道与权限

| 通道 | 操作 | 需要权限 | 默认 | 里程碑 |
|---|---|---|---|---|
| A 服务菜单 | 选中文本右键 → 服务 →「Gloss 查词」 | 无 | 开 | M1 |
| B 划词快捷键 | ⌥D | 辅助功能（AX 取词 + ⌘C 兜底） | 开 | M1 |
| C 截图快捷键 | ⌥S | 屏幕录制（若实测子进程豁免则移除此要求，实现期校准） | 开 | M1 |
| D 打开/拖拽 PDF | 菜单栏入口 / 拖拽到菜单栏图标 | 无 | — | M2 |
| E 选区跟随 | 选中自动浮小图标 | 辅助功能 | 关 | M3 |

快捷键冲突：注册失败（已被占用）时设置页红字提示并要求改键；快捷键均可在设置中自定义。

## 6. 设置窗（四页签）

**模型**：Provider 下拉（MiniMax〔默认〕/ OpenAI / DeepSeek / 智谱 GLM / Kimi / 自定义）；选 MiniMax 时出"区域"单选（国内/国际，决定端点）；API Key（SecureField + 显示切换 + 粘贴即存 Keychain）；模型名（默认 MiniMax-M3，可编辑——模型 ID 以厂商控制台为准）；温度滑条（0–1，默认 0.3）；「测试连接」按钮（发一次最小请求，显示延迟与成功/失败原因）；多套配置保存与一键切换（切换后全局生效——查词与精读共用当前活动配置；按查询类型分用不同配置列入 M3 评估）。
**触发**：五通道开关（按里程碑禁用未上线项）+ ⌥D/⌥S 快捷键录制控件；「恢复默认快捷键」。
**朗读**：音色下拉（枚举系统英文音色，Siri/Ava 类优质音色置顶并标注"需在系统设置下载"）+ 每项「试听」；语速滑条 0.5–1.5×；默认音色美/英各设一个。

## 7. 历史窗

列表（时间倒序）：类型徽标（词/句/段/图/读——精读结果记为"读"）、输入预览（词/句截断 40 字，截图显示缩略图）、模型名、⭐（M3 生词本前身，M1 仅本地标记）。顶部搜索框（包含匹配）+ 「清除全部」（二次确认）。点击一条 → 词/句/段条目浮窗回放该结果（缓存态）并可「重新查询」；「读」条目点击重开精读窗（四 Tab 内容不适配 400pt 浮窗）；截图条目仅回放不重查（原图不持久化，重查请重新 ⌥S）。

## 8. 文案规范

- 语言：简体中文界面；英文术语保留原文（API Key、Provider、Tab 名「翻译/生词/术语/解读」）。
- 错误文案人话化：网络失败→"网络连不上，检查后重试"；401→"API Key 无效或已过期"；429→"请求太频繁，已自动重试仍受限，稍后再试或换个模型配置"；超时→"模型响应超时"。
- 涉及发送数据的披露：「设置 > 高级」页与首启向导均注明：查询内容仅发送给你配置的模型服务商；开启第三方词典首屏时单词另发给该词典服务。
- 不使用感叹号与拟人语气；按钮动词开头（查询/复制/重试/固定）。

## 9. 状态与边界全表

| 状态 | 界面表现 | 自动动作 |
|---|---|---|
| 未配置 Key 即查询 | 浮窗提示条「未配置 API Key · 去设置」 | 无 |
| AX+⌘C 双失败 | 降级卡：说明 + 「改用截图查询 ⌥S」 | 无 |
| 截图被 ESC 取消 | 不弹窗 | 无 |
| 流式空闲超时（>20s 无**任何** delta，连思考都没有：流假活/SSE 空转） | 错误态「模型响应超时」+「重试」 | 自动取消请求 |
| 思考过长（>90s 持续有思考流但零正文：思考死循环） | 错误态「模型思考时间过长」+「重试」 | 自动取消请求 |
| 模型思考中（正常长思考，图上点词/密集页实测 4–20s+） | 骨架屏内实时滚动思考流尾部（固定高 ~3 行）+「思考中 · Ns」秒表；**不再按「无正文」误杀** | 思考期间不打断；正文到达即收起思考区 |
| 429/5xx | 自动重试 2 次（1s/3s 退避），仍失败出错误态 | 重试 |
| 输入含敏感格式（如全数字/超长单串） | 正常查询；路由器不特殊处理 | 无 |
| 剪贴板恢复失败 | 无感知（不提示），设置页说明"⌘C 兜底会临时使用剪贴板，尽力恢复" | 尽力恢复 |
| 全屏 App 内触发 | 浮窗仍可显示（fullScreenAuxiliary） | 无 |
| 系统无高质量英文音色 | 音色下拉回退默认音色并标注 | 无 |
| 右键服务菜单不出现 | 设置引导：系统设置→键盘→键盘快捷键→服务 中勾选「Gloss 查词」（通常注销重登后生效） | 无 |
| 网络失败 | 错误态「网络连不上，检查后重试」 | 无 |
| 精读分批中单批失败 | 该批标记失败、其余批次继续；失败批显示「重试本批」 | 跳过继续 |
